### Facts to state accurately (from CLAUDE.md invariants; link `CLAUDE.md` rather than copying it)

- `internal/agent` never imports `internal/frappe`; the agent reaches ERPNext only through MCP.
- The MCP admin token is used only by `internal/approvals`; write tools exist only on `/mcp-admin` (books server). Read tools carry `readOnlyHint`.
- Retrieved document text never reaches a model that can call tools. The explainer's only tool is `emit_explanation`; the investigator has no `search_documents` and no admin tool.
- Every MCP call is scoped to the run's company and month (CC-506); the company filter sits inside the SQL, before ranking (CC-804).

- Money is `int64` paise; maker-checker: Asha proposes, Ravi approves, self-approval is refused (CC-1004).
- Read-only MCP tool catalog (docs/mcp.md): books server `:7001` `/mcp`: `get_trial_balance`, `list_gl_entries`, `list_purchase_invoices`, `list_sales_invoices`, `list_payments`, `get_account_history`, `list_recurring_suppliers`; evidence server `:7002` `/mcp`: `list_bank_lines`, `list_gstr2b_entries` and `search_documents` (read-only, company-scoped, snippets of at most 600 characters, document types from a fixed list; `internal/evidence/tools.go:77`).

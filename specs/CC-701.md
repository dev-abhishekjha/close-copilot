# CC-701 · LLM provider interface and Anthropic implementation

## Goal

A model-agnostic `llm.Provider` with tool calling, prompt caching, retries, and per-call cost accounting, implemented with the official Anthropic Go SDK and local Claude CLI.

## Context

- Ticket: `docs/implementation-tickets.md`, section `CC-701`.
- Plan row: Phase 1, llm-engineer, risk data-sensitive, gates G1–G3, G5.
- Plan change (ADR 0001): Supports two providers:
  - `Anthropic`: API provider using `anthropic-sdk-go` and `internal/httpx`.
  - `ClaudeCLI`: local CLI provider selected by `LLM_PROVIDER=claude-cli` using `claude -p --output-format json`.
- Prompt caching: ephemeral cache control on system prompt blocks.
- Pricing table: `config/pricing.yaml` defining input, output, cache-write, and cache-read costs per million tokens.
- Unit tests use `FakeProvider` and fake process execution; live tests run behind `//go:build live`.

## Subtasks

- [ ] **`config/pricing.yaml`:**
  - Token pricing table for Claude models (Haiku, Sonnet, Opus).
- [ ] **`internal/llm/llm.go` & `pricing.go`:**
  - `Provider` interface: `Complete(ctx context.Context, req Request) (Response, error)`.
  - Core types: `Request`, `Response`, `Block`, `Message`, `ToolSpec`, `ToolCall`, `ToolResultBlock`, `Usage`.
  - `LoadPricing` and token cost calculator.
  - Scripted `FakeProvider` for testing.
- [ ] **`internal/llm/anthropic.go`:**
  - Anthropic SDK client integration with `internal/httpx`.
  - Tool calling conversion (`ToolSpec`, `ForceTool`, `ToolCall`, `ToolResultBlock`).
  - Ephemeral prompt caching on cacheable system blocks.
  - Exponential backoff retries on 429, 500, 529 honoring `Retry-After`.
- [ ] **`internal/llm/claudecli.go`:**
  - `ClaudeCLI` provider executing `claude -p` via `ProcessRunner` interface.
  - Flag construction, stdin formatting, JSON result parsing.
- [ ] **Tests (`internal/llm/*_test.go`):**
  - Fake provider round trip and request inspection.
  - Pricing table calculation tests.
  - Anthropic request mapping, prompt cache control, and retry behavior.
  - Claude CLI command execution, schema mapping, and response parsing.
  - Live test tagged `//go:build live`.

## Acceptance (human-readable)

- Unit tests with `FakeProvider` and fake runners pass with race detection.
- Anthropic and Claude CLI implementations correctly format tools, system blocks, and calculate usage cost.
- Retries and backoff handle transient rate limits and server errors.
- `make check` passes cleanly.

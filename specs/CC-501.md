# CC-501 · Shared MCP server scaffold

## Goal

`internal/mcpkit` starts an MCP server over Streamable HTTP or stdio, with bearer-token auth, request IDs, structured logs, `/healthz`, and graceful shutdown.

## Context

- Ticket: `docs/implementation-tickets.md`, section `CC-501`.
- Uses official Go MCP SDK (`github.com/modelcontextprotocol/go-sdk/mcp`).
- Shared scaffold for `mcp-books` (`/mcp` and `/mcp-admin`) and `mcp-evidence` (`/mcp`).
- Plan row: Phase 1, integration-engineer, risk data-sensitive, gates G1-G3, G5.

## Subtasks

- [ ] **MCPKit Server & Transport (`internal/mcpkit/`):**
  - `NewServer(name, version string) *mcp.Server`: constructs an SDK server instance.
  - `ServeHTTP(ctx context.Context, addr string, routes map[string]Route, log *slog.Logger) error`: mounts routes with Streamable HTTP handlers.
  - `RunStdio(ctx context.Context, server *mcp.Server) error`: connects and runs via `mcp.StdioTransport`.
  - `/healthz` endpoint returning HTTP 200 without requiring auth.
- [ ] **Middleware Chain & Security:**
  - Request ID injection (`X-Request-ID`).
  - Structured access logging (`slog`) recording path, method, status, and duration.
  - Panic recovery middleware returning HTTP 500.
  - Bearer token authentication with constant-time comparison (`crypto/subtle.ConstantTimeCompare`). Missing or invalid tokens receive HTTP 401 Unauthorized.
  - Admin token handling isolated to `internal/mcpkit/auth*.go` to satisfy the `admintoken` analyzer.
- [ ] **Graceful Shutdown:**
  - HTTP server shuts down gracefully on context cancellation with a 10 s timeout.
- [ ] **Binary Integration (`cmd/mcp-books/`, `cmd/mcp-evidence/`):**
  - `--transport=http|stdio` flag; stdio mode for direct MCP CLI usage.
  - `mcp-books` mounts `/mcp` with agent token and `/mcp-admin` with admin token.
  - `mcp-evidence` mounts `/mcp` with agent token.
- [ ] **Tests (`internal/mcpkit/*_test.go`, `cmd/mcp-*/*_test.go`):**
  - Bearer auth test: valid token passes; missing or invalid token gets 401.
  - `/healthz` check returns 200.
  - Stdio transport execution test.
  - Request ID and panic recovery tests.

## Acceptance (human-readable)

- MCP Inspector connects over HTTP with the right token and lists zero tools; a wrong or missing token gets 401.
- The same binary runs in stdio mode.

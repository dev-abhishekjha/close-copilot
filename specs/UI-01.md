# UI-01 · Design tokens, stylesheet rewrite, self-hosted font and icon sprite

## Goal

One design system in CSS that every later UI ticket builds on: tokens, a base layer, the existing pages restyled onto the tokens, a self-hosted font and an icon sprite, all inside the current strict CSP, with no change to any page's markup.

## Context

- Ticket: `tasks/frontend-plan.md`, sections 3, 5 and 10 (`UI-01`); not in `docs/implementation-tickets.md`.
- Why: the stylesheet is one 128-line file with a handful of colours. The UI plan needs tokens (light and dark), a type scale, and an icon set before any component is built. Look: calm, dense, Xero-like; Indian-format money is a later ticket, but numbers must already align (tabular figures).
- CSP (`internal/web/middleware.go:20`) allows only `'self'`: `style-src 'self'`, `font-src 'self'`, `img-src 'self'`. No inline style, no `<style>`, no external URL. **This ticket does not change the CSP and does not touch templates.** Every page keeps its current markup and class names; only how they look changes.
- Existing tests assert markup and `/static/app.css` returning `text/css` (`server_test.go:104`, `routes_test.go:326`). They must pass untouched.

### Tokens (the contract later tickets use)

Define in `css/tokens.css` on `:root` (light), again for dark under both `@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) { ... } }` and `:root[data-theme="dark"] { ... }` (the two dark blocks must hold identical values). Colours are 6-digit hex so the test can parse them.

- Colour: `--color-bg`, `--color-surface`, `--color-surface-2`, `--color-border`, `--color-border-strong`, `--color-fg`, `--color-fg-muted`, `--color-fg-subtle`, `--color-accent`, `--color-accent-hover`, `--color-accent-soft`, `--color-on-accent`, `--color-focus`, and for each of `sev-high`, `sev-med`, `sev-low`, `ok`, `warn`, `danger`, `info`: `--color-<name>` (text and icon colour) and `--color-<name>-soft` (background).
- Space (4px scale): `--space-1` 0.25rem, `-2` 0.5rem, `-3` 0.75rem, `-4` 1rem, `-5` 1.25rem, `-6` 1.5rem, `-8` 2rem, `-10` 2.5rem, `-12` 3rem.
- Radius: `--radius-sm` 4px, `--radius-md` 6px, `--radius-lg` 10px, `--radius-pill` 999px.
- Shadow: `--shadow-sm`, `--shadow-md`, `--shadow-lg` (subtle; in dark they may be heavier).
- Type: `--font-sans` (Inter, then the system stack), `--font-mono`, `--text-xs` 0.75rem, `--text-sm` 0.8125rem, `--text-base` 0.875rem, `--text-md` 1rem, `--text-lg` 1.25rem, `--text-xl` 1.5rem, `--text-2xl` 1.875rem, `--leading-tight` 1.25, `--leading-normal` 1.5.
- Layout and layers: `--layout-sidebar-w` 15rem, `--layout-content-max` 72rem, `--z-sidebar` 20, `--z-topbar` 30, `--z-modal` 40, `--z-toast` 50, `--focus-ring` (a `0 0 0 3px` ring using `--color-focus`).

Suggested light palette (adjust only where the contrast test demands): bg `#f6f7f9`, surface `#ffffff`, surface-2 `#eef1f5`, border `#e1e5ec`, border-strong `#c9d0db`, fg `#151a24`, fg-muted `#4a5468`, fg-subtle `#5f6a7e`, accent `#1b5fd1`, accent-hover `#1449a8`, accent-soft `#e8f0fc`, on-accent `#ffffff`, focus `#1b5fd1`; sev-high `#b42318` on `#fdecea`; sev-med `#9a4a05` on `#fef3e2`; sev-low `#34558b` on `#e9eff8`; ok `#176b43` on `#e5f4ec`; warn `#8a5a00` on `#fdf3d7`; danger `#b42318` on `#fdecea`; info `#34558b` on `#e9eff8`. Dark: bg `#0f131a`, surface `#171c26`, surface-2 `#1e2430`, border `#2a3140`, fg `#e8ebf1`, muted `#a9b2c3`, accent `#7aa8ff`, on-accent `#0b1220`, with each severity text a light tint on a dark soft background.

### Icons

`/static/icons.svg` is a sprite of 24x24 `<symbol id="icon-<name>" viewBox="0 0 24 24">` stroke icons (`fill="none" stroke="currentColor" stroke-width="1.75" stroke-linecap="round" stroke-linejoin="round"`). Ids: `home`, `play`, `alert`, `message`, `check-circle`, `file-text`, `book`, `shield`, `bar-chart`, `server`, `search`, `plus`, `check`, `x`, `chevron-down`, `chevron-right`, `external`, `download`, `refresh`, `user`, `log-out`, `sun`, `moon`, `info`, `lock`, `filter`, `copy`, `menu`, `clock`, `trash`. Use Lucide paths (ISC licence) or draw your own; record the source and licence text in `static/LICENSES.txt`, with the font's licence.

### Font

Inter variable (SIL OFL 1.1), as `inter-latin.woff2` and `inter-latin-ext.woff2` (the latter carries the rupee sign U+20B9) under `static/fonts/`. A source is the Fontsource files on jsDelivr, e.g. `https://cdn.jsdelivr.net/npm/@fontsource-variable/inter@5.1.0/files/inter-latin-wght-normal.woff2` and `...inter-latin-ext-wght-normal.woff2`; download once with `curl` into the declared paths. Declare two `@font-face` rules with `font-weight: 100 900`, `font-display: swap`, `unicode-range` as Fontsource publishes it, and `src: url("/static/fonts/...") format("woff2")`. If the download fails, stop and tell the orchestrator; do not substitute a different font.

## Code map

- `internal/web/static/app.css` (128 lines): today holds everything. Becomes only `@import url("/static/css/tokens.css"); @import url("/static/css/base.css"); @import url("/static/css/legacy.css");` plus a short header comment.
- `internal/web/static/css/tokens.css`: tokens and `@font-face`.
- `internal/web/static/css/base.css`: reset, `html`/`body`, headings, links, form controls (input, select, textarea, button and its disabled state), tables, `details`, `:focus-visible` using `--focus-ring`, `.num` (right-aligned, `font-variant-numeric: tabular-nums`), `.visually-hidden`, `prefers-reduced-motion`, and the existing `.htmx-indicator` rules (htmx's own indicator style is disabled, see `templates/pages.go` `htmxConfig`).
- `internal/web/static/css/legacy.css`: the page classes the current templates use, restyled onto tokens: `topbar brand who role user card narrow inline error actions action nav-link banner facts evidence-block evidence totals note summary summary-run summary-high summary-verified filters approvals lines own posted audit steps badge verified unverified status severity runs findings start-run timeline trace` and the `data-severity` / `data-status` / `data-role` attribute selectors in use. Find them with `grep -ohE 'class="[^"]+"' internal/web/templates/*.templ` and `grep -ohE 'data-[a-z-]+' internal/web/templates/*.templ`; do not edit templates. Severity and status must differ by text or shape as well as colour (the templates already print the words).
- `internal/web/static/` is embedded by `//go:embed static` at `internal/web/server.go:31`, so sub-directories ship automatically. `staticFiles` is the embed FS the tests read.
- `internal/web/mime.go` (new): an `init()` calling `mime.AddExtensionType(".woff2", "font/woff2")` so `/static/fonts/*.woff2` is served with the right type on any host. Register `.svg` as `image/svg+xml` the same way if the host table lacks it.
- Style to copy for tests: `internal/web/server_test.go:101` `TestStaticAndHealthz` (uses `newTestServer`, `ts.do`).

### Tests (package `web`, file `design_test.go`)

- `TestDesignTokensContrast`: parse `--color-*` hex values from `tokens.css` for light and dark; compute WCAG contrast; require at least 4.5 for fg, fg-muted and fg-subtle on bg, surface and surface-2; accent on surface; on-accent on accent and accent-hover; each `--color-<name>` on its `-soft` for the seven severity/status names; and at least 3 for `--color-focus` on surface and bg. The two dark blocks must be identical. Every token named in Tokens exists in light and dark.
- `TestDesignStylesheetRules`: every file under `static/css/` and `app.css`: no `style=`, no `url(` pointing at `http:`, `https:` or `//`, no `@import` of anything outside `/static/css/`; every `@import` target exists in `staticFiles`; `prefers-reduced-motion` and `:focus-visible` present.
- `TestDesignLegacyClassesStyled`: collect the class names from `templates/*.templ` (read from disk with a path relative to the package dir) and require each to appear in a selector in `legacy.css` or `base.css`, except an explicit `unstyledOK` list in the test (pure hooks such as `count`, `ids`, `label`; each with a comment).
- `TestStaticFonts`: via the test server, both woff2 files return 200, `Content-Type: font/woff2`, and start with the `wOF2` magic bytes; the `@font-face` `src` URLs resolve to embedded files; `/static/app.css` is still `text/css`.
- `TestIconSprite`: `/static/icons.svg` is `image/svg+xml`, parses as XML, and contains a `<symbol>` for each listed id with `viewBox="0 0 24 24"` and no `<script>`, `on*=` attribute or external reference.

## Acceptance (human-readable)

- All existing web tests pass with no edit to a template or test.
- A person opens the app in light and dark OS mode and sees the same pages in a calmer, consistent style: readable text, visible focus on every control, severity and status readable without colour.
- The CSP constant, templates, `server.go` and `routes.go` are untouched (the `git diff --quiet main` acceptance line).

## Out of scope

- Templates, new components (UI-02), the shell and theme toggle (UI-03; this ticket only supports the `data-theme` attribute in CSS), Indian number formatting, any JavaScript.
- Preloading the font (needs a template change).

# CC-002 · Custom static analyzers

## Goal

Four architecture rules a reviewer would otherwise have to remember fail the build in G2.

## Context

- Ticket: `docs/implementation-tickets.md`, section `CC-002` (it has a worked `noerpimport` example). Plan: "Guardrails", the row "Write-capable MCP tools stay out of the answer path".
- Each rule guards one invariant from `CLAUDE.md`: exact money, the write path, the MCP boundary and outbound traffic.
- Write the rules with `golang.org/x/tools/go/analysis` and run them through a multichecker binary, `gates/cmd/lint`. golangci-lint plugins would need a custom build.
- Dependencies: `golang.org/x/tools` is already in `go.mod`, pinned through `internal/deps/deps.go`. Once real code imports `golang.org/x/tools/go/analysis`, delete that line from `deps.go`. Leave the other lines. Run `go mod tidy` if `go.sum` needs entries for `analysistest` or `multichecker`. **No other new dependencies.**
- Module path `github.com/abhishekjha/close-copilot`. Config field names: `Config.MCPTokenAdmin`, env constant `EnvMCPTokenAdmin` (`MCP_TOKEN_ADMIN`), both in `internal/config/config.go`.
- CC-001 is being built in parallel. It owns `gates/*.go`, `gates/cmd/{graph,ready,declared,protected}` and `.github/**`; don't touch them. Its CI job runs `go run ./gates/cmd/lint ./...` once this directory exists.

## Subtasks

- [ ] Package scope helper: match packages by import-path segments, not raw substrings.
  - `internal/agent` covers `…/internal/agent` and its subpackages, but not `…/internal/agentx`.
  - It must work both for the real module path and for `analysistest` GOPATH-style paths such as `internal/agent/bad`.
- [ ] **`nofloat`**: report any declaration or expression of type `float32` or `float64`, including untyped float constants that default to `float64`, in these packages:
  - `internal/checks`, `internal/books`, `internal/evidence`, `internal/seed`, `internal/approvals`, `internal/agent`.

  Only `internal/money` converts. CC-203 decodes ERPNext amounts as `json.Number`. Retrieval scores (`internal/retrieval`) and LLM cost (`internal/llm`) stay outside the list.
- [ ] **`admintoken`**: report any reference to `config.Config.MCPTokenAdmin`, to `config.EnvMCPTokenAdmin`, or to the string literal `"MCP_TOKEN_ADMIN"` outside these allowed places:
  - `internal/config`, which loads it;
  - `internal/mcpkit` files named `auth*.go`, which verify it;
  - `internal/approvals`, which uses it.

  One narrower exception, added by the owner on 2026-10-08: `cmd/mcp-books` may reference the **name**, `config.EnvMCPTokenAdmin` (or `"MCP_TOKEN_ADMIN"`), so it can require the variable at startup, because that server hosts `/mcp-admin`. It must never reference the **value**, `Config.MCPTokenAdmin`. Add testdata for both: the name allowed in `cmd/mcp-books`, the field flagged there.
- [ ] **`noerpimport`**: `internal/agent` and its subpackages never import `internal/frappe`. This applies to test files too.
- [ ] **`egress`**: outside `internal/httpx`, report:
  - calls to `http.Get`, `http.Head`, `http.Post` and `http.PostForm`;
  - any use of `http.DefaultClient` or `http.DefaultTransport`;
  - composite literals `http.Client{…}` and `&http.Client{…}`.
- [ ] Test files (`_test.go`) are exempt from `nofloat`, `admintoken` and `egress` (tests use `httptest` and float assertions), but not from `noerpimport`. Document this in each analyzer's `Doc`.
- [ ] **`internal/httpx`**:
  - `New(cfg config.Config, opts ...Option) (*http.Client, error)` returns a client with a timeout (default 30 s; an `Option` can change it).
  - Its transport refuses any request whose host isn't in the allowlist, with an error that names the host.
  - The allowlist is the hosts of `ERPBaseURL`, `BooksMCPURL`, `EvidenceMCPURL`, `TEIEmbedURL`, `TEIRerankURL` and `DoclingURL`, the host of `OTEL_EXPORTER_OTLP_ENDPOINT` when set, and `api.anthropic.com`.
  - Redirects to a refused host fail, because every hop passes through the transport.
- [ ] `analysistest` testdata under `gates/analyzers/testdata/src/`, with one violating and one clean package per rule. Violations carry `// want "…"` comments.
- [ ] `gates/cmd/lint/main.go`: `multichecker.Main(nofloat.Analyzer, admintoken.Analyzer, noerpimport.Analyzer, egress.Analyzer)`. One package per analyzer under `gates/analyzers/<name>/` is fine, or one package exporting four analyzers. Pick one and keep it consistent.
- [ ] `Makefile`: `lint` runs `golangci-lint run`, then `$(GO) run ./gates/cmd/lint $(PKGS)`. `make check` already depends on `lint`.

## Acceptance (human-readable)

- The analyzer tests flag every forbidden pattern in testdata and pass the clean packages:
  - a float field in `internal/checks`, an untyped `1.5` in `internal/books`, and a float in `internal/agent/sub`;
  - `cfg.MCPTokenAdmin` in `internal/agent` and `os.Getenv("MCP_TOKEN_ADMIN")` in `internal/books`;
  - a `frappe` import in `internal/agent`;
  - `http.Get` and `&http.Client{}` in `internal/frappe`.
- **Clean cases:**
  - a float in `internal/retrieval` and in `internal/llm`;
  - `MCPTokenAdmin` in `internal/approvals` and in `internal/mcpkit/auth.go`, but **not** in `internal/mcpkit/server.go`;
  - an `http.Client{}` in `internal/httpx`.
- The `httpx` tests use `httptest`: an allowed host gets a response, a refused host gets an error naming it, and a redirect to a refused host fails.
- `go run ./gates/cmd/lint ./...` and `make check` are clean on the repo as it stands.
- Owner checks (G6): each rule's scope list against `CLAUDE.md`'s invariants, and that the test exemptions are acceptable.

## Out of scope

- **Moving existing callers onto `httpx`:** there are none yet. Later tickets (CC-202, CC-701, CC-802) build their clients with `httpx.New`.
- **Other G2 items** (gitleaks, the MCP tool-schema snapshot diff): later tickets.

## Notes

- `internal/config` keeps `LLMDailyBudgetUSD float64`. The `config` package isn't in `nofloat`'s list. Budget enforcement belongs in `internal/llm`, so `internal/agent` must not read that field.
- Use type information (`pass.TypesInfo`) for `nofloat` and `admintoken`, not names: a local type called `float64` or a field called `MCPTokenAdmin` on another struct must not trip them.

# UI-11 · Documents browser

## Goal

A read-only page where any signed-in user lists the documents the corpus holds for the selected company (plus the shared policy), filters by type, and opens one to read its sections, with the company filter inside the SQL so another company's text can never be fetched.

## Context

- Ticket: `tasks/frontend-plan.md` section 6, row `UI-11`: "Documents browser: list, filter by type, document view with sections; list endpoint on retrieval if missing". Data-sensitive, so G5 runs: corpus text is customer data. View pages show corpus text to humans only, never to a model (CLAUDE.md invariant: retrieved document text never reaches a model that can call tools). This page adds no model access and calls no tool.
- **Table (`migrations/0003_docs.sql`, read only; do not edit migrations):** `doc_chunks(id bigserial PK, doc_id text NOT NULL, doc_type text NOT NULL, company_id text NULL, section text NULL, title text NULL, content text NOT NULL, content_hash text NOT NULL, embedding vector(384), tsv ...)`. `company_id` is NULL for the shared policy. `doc_type` is one of `policy` (shared, e.g. `POL-001-accounting-policy`), `contract` and `close_note` (per company). Ingest (`ingest.go` `docFromPath`) sets `doc_id` to the file stem. A document is all rows with one `doc_id`; its chunks in `id` order are its sections in reading order (ids are assigned as chunks are inserted).
- **Company filter in the SQL (CC-804, the part that must not be missed).** Every query in `list.go` carries `(company_id IS NULL OR company_id = $1)` in its own WHERE clause, the same predicate `buildSQL` uses (`search.go:192`), before any grouping, ordering or limit. Never fetch by `doc_id` alone and filter in Go. An empty company is refused with an error (`ErrNoCompany`) before any query runs; do not let it fall through to "shared only". A document of another company answers exactly like a missing one (`ErrDocNotFound`, page 404), so ids are not an oracle.
- **Company comes from the session context, not the request.** Use `Server.contextFor(r)` (shell.go:199), which validates the `cc_ctx` cookie against the real company list. Do not read a company from a query string or form field. The shell's company switcher (`POST /context`) already changes it. When `contextFor` returns an empty company, render an `EmptyState` "No company selected".
- **Retrieval additions (`internal/retrieval/list.go`)**, no change to `search.go`, `ingest.go` or migrations:
  - `type DocSummary struct { DocID, DocType, Title string; CompanyID *string; Sections int }` (Title is the title of the document's first chunk; `Sections` is the chunk count).
  - `type DocSection struct { Section, Content string }`.
  - `type Document struct { DocID, DocType, Title string; CompanyID *string; Sections []DocSection }`.
  - `var ErrNoCompany`, `ErrDocNotFound` (plain `errors.New`, wrapped with `%w` by callers).
  - `type Lister struct{ db Querier }`; `func NewLister(db Querier) *Lister`.
  - `func (l *Lister) ListDocuments(ctx context.Context, company string, docTypes []string) ([]DocSummary, error)`: one grouped query, ordered by `doc_type, doc_id`, `LIMIT 500`; `docTypes` empty means all types, otherwise `doc_type = ANY($2)` inside the same WHERE.
  - `func (l *Lister) GetDocument(ctx context.Context, company, docID string) (Document, error)`: `WHERE doc_id = $2 AND (company_id IS NULL OR company_id = $1) ORDER BY id`; no rows is `ErrDocNotFound`.
  - Use `retrieval.Querier` (`search.go:55`), which `*pgxpool.Pool` satisfies (`store.Store.Pool()`). No embedder, no TEI, no model.

## Page

- `GET /documents`: `PageHeader` "Documents", subtitle "Policy and contracts for the selected company. Shared policy applies to every company." A row of type filter links (All, Policy, Contract, Close note) as `?type=policy|contract|close_note`; the current one has `aria-current="page"`. Any other `type` value is ignored (treated as All; never echoed). A `DataTable` of title (link to `/documents/{id}`), doc id, type (`StatusChip`-style label), scope ("Shared" when `CompanyID` is nil, else the company), and section count. Empty result: `EmptyState` "No documents for this company". Sort by type then id as returned.
- `GET /documents/{id}`: `PageHeader` with the title, `Facts` (doc id, type, scope, number of sections), a back link to `/documents`, then one `Card` per section: the section name (or "Section N" when empty) as the heading and the text in `<div class="doc-text">`. Text is escaped by templ, shown with `white-space: pre-wrap; overflow-wrap: anywhere` in `documents.css`, with no markdown and no HTML interpretation and never `templ.Raw`. Unknown, other-company or malformed id: the same 404 page (`EmptyState` "Document not found", status 404). A `{id}` must match `^[A-Za-z0-9][A-Za-z0-9._-]{0,99}$` before the backend is called; otherwise 404 without a call.
- Backend errors (other than `ErrDocNotFound`): 500 with a fixed "Something went wrong" page; the cause goes to the log with the doc id and company only, never the document text.
- Response headers: no caching of document text (`Cache-Control: no-store`) on both pages.
- Stateless and read-only: no POST routes, nothing stored, no cookie set.

## Acceptance (human-readable)

- A user opens Documents from the sidebar, sees the policy and the selected company's contracts and close notes, filters by type, opens a document and reads its sections. Switching company in the shell changes the list.
- Typing another company's document id in the URL shows "Document not found", the same as an id that does not exist.
- G5 can confirm: both SQL statements filter by company inside the WHERE; the company never comes from request input; document text is escaped, not logged, not cached and never sent to a model; no new write path.

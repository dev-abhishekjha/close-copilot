# CC-503 · Evidence server

## Goal

`mcp-evidence` exposes `list_bank_lines` and `list_gstr2b_entries` from Postgres over Streamable HTTP and stdio; Inspector lists both tools; results match the loaded files row for row.

## Context

- Ticket: `docs/implementation-tickets.md`, section `CC-503`.
- Shared specs: `Bank statement`, `GSTR-2B` inward supply return, `mcp-evidence` server.
- Plan row: Phase 1, integration-engineer, risk data-sensitive, gates G1-G3, G5.
- Both tools carry `Annotations: &mcp.ToolAnnotations{ReadOnlyHint: true}`.
- Mounts under `/mcp` with bearer-token auth (agent token).

## Subtasks

- [ ] **Evidence MCP Tools (`internal/evidence/tools.go`):**
  - Implement `RegisterTools(server *mcp.Server, st *store.Store)`:
    - Tool `list_bank_lines`: company, from_date, to_date, optional min_amount (in paise). Ordered by date then txn_id.
    - Tool `list_gstr2b_entries`: company, period, optional supplier GSTIN. Ordered by invoice_date, supplier_gstin, invoice_no_norm.
  - Return typed outputs matching the shared spec.
  - Set `Annotations: &mcp.ToolAnnotations{ReadOnlyHint: true}` on both tools.
- [ ] **Binary Integration (`cmd/mcp-evidence/`):**
  - Connect to database via `store.Open(ctx, cfg.DatabaseURL.Reveal())`.
  - Register tools on `evidenceServer` before starting HTTP or stdio transport.
- [ ] **Unit & Integration Tests (`internal/evidence/tools_test.go`, `cmd/mcp-evidence/main_test.go`):**
  - Test `list_bank_lines` returns expected rows matching loaded data, respecting date range and min_amount filter.
  - Test `list_gstr2b_entries` returns expected rows matching loaded data, respecting period and supplier_gstin filter.
  - Test MCP Inspector/client handshake over HTTP with agent bearer token: lists both tools with read-only hint.
  - Verify error handling for invalid dates and missing required arguments.

## Acceptance (human-readable)

- Inspector lists both tools (`list_bank_lines`, `list_gstr2b_entries`); results match the loaded files row for row.
- Bearer token authentication protects `/mcp`.
